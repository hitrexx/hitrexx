# AI Estimate

Telegram-бот для автоматического расчёта предварительных строительных смет с
помощью ИИ. Бот принимает прайс-лист компании и проект (PDF/Word/фото),
определяет виды и объёмы работ через ИИ, считает стоимость программно (без
участия ИИ в математике) и присылает готовую смету текстом, Excel и PDF.

## Как это работает

1. `/start` → «Создать смету»
2. Пользователь загружает Excel-прайс-лист (Код, Наименование, Единица, Цена
   работы, Цена материала)
3. Блиц-опрос: тип объекта, площадь, этажность, материалы, регион и т.д.
4. Пользователь загружает проект (PDF / DOCX / фото чертежей)
5. ИИ анализирует проект и возвращает JSON с видами и объёмами работ —
   **без цен**
6. Программа сопоставляет работы с прайс-листом и считает стоимость
7. ИИ повторно проверяет смету на предмет пропущенных этапов (гидроизоляция,
   утепление, армопояс и т.п.)
8. Бот присылает итоговую смету сообщением + файлами Excel и PDF

## Стек

- Python 3.11+, aiogram 3 (Telegram)
- Google Gemini (`google-genai`) — анализ проекта, вынесен за интерфейс
  `AIProvider` (`app/ai/base.py`), чтобы в будущем заменить на Claude Opus без
  переписывания остального кода — см. `app/ai/factory.py`
- openpyxl — прайс-лист и экспорт в Excel
- PyMuPDF (`fitz`) — разбор PDF (текст + рендер страниц как изображения для ИИ)
- python-docx — разбор Word-документов
- reportlab — экспорт в PDF (с встроенным шрифтом DejaVuSans для кириллицы)
- SQLite — хранение пользователей, прайс-листов, проектов и смет (MVP)

## Структура проекта

```
app/
  handlers/     — Telegram-хендлеры (aiogram, FSM-сценарий)
  services/     — оркестрация полного пайплайна расчёта сметы
  ai/           — слой ИИ (интерфейс + реализация на Gemini)
  parser/       — разбор Excel-прайса и PDF/Word/изображений проекта
  calculator/   — сопоставление работ с прайсом и расчёт стоимости (без ИИ)
  exports/      — экспорт сметы в Excel и PDF
  database/     — SQLite-схема и доступ к данным
main.py         — точка входа бота
```

## Запуск

1. Установите зависимости (Python 3.11+):

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate   # на Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и заполните:

   ```bash
   cp .env.example .env
   ```

   - `TELEGRAM_BOT_TOKEN` — получить у [@BotFather](https://t.me/BotFather)
   - `GEMINI_API_KEY` — получить в [Google AI Studio](https://aistudio.google.com/apikey)

3. Запустите бота:

   ```bash
   python main.py
   ```

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты покрывают разбор прайс-листа, разбор проектных файлов, сопоставление
работ с прайсом, расчёт сметы, экспорт в Excel/PDF и полный пайплайн сервиса
(с фейковым ИИ-провайдером, без реального обращения к Gemini).

## Логирование

- `logs/requests.log` — все действия пользователей
- `logs/errors.log` — ошибки отдельно

## Важное архитектурное решение

ИИ **никогда** не считает деньги — только определяет виды работ, объёмы и
проверяет полноту сметы. Вся арифметика (`work_price × volume` и т.п.)
выполняется в `app/calculator/calculator.py` обычным кодом.

## Не входит в MVP (по ТЗ)

Личный кабинет, веб-версия, несколько прайс-листов, работа нескольких
сотрудников, интеграция с CRM, экспорт в коммерческое предложение,
календарный график, расчёт сроков, сравнение смет, история проектов, API.
